## Build principles

- Clear scope and explicit assumptions
- Evidence-first outputs instead of vague conclusions
- Capabilities, system access and side effects stated explicitly
- Read-only tools remain read-only
- Reproducible workflows and useful reports
- Public GitHub repositories for trust, documentation and free tools
- Paid customer packages stay on the official checkout channels
